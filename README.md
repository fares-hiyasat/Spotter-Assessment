# Freight Rate Prediction – ML Assessment

## Overview

This project builds a machine learning regression model to predict freight rates.

The development dataset contains 48,000 labeled loads. The final model is used to generate predictions for 12,000 unseen validation loads and for the fixed December 2025 scenario provided with the assessment.

## Approach

### Data Preparation

The data was explored for missing values, feature types, and categorical variables.

Missing values were handled using:
- Median imputation for numerical features
- Most-frequent imputation for categorical features

The date column was converted to datetime, with month and day of week extracted as features.

`load_id` was excluded from the model because it is an identifier.

### Features

The main model uses the following features.

**Numerical**
- pickup_lat
- pickup_lon
- delivery_lat
- delivery_lon
- distance
- weight
- market_index
- quote_signal
- month
- day

**Categorical**
- pickup
- delivery
- equipment

Categorical features are one-hot encoded.

### Model Selection

Random Forest and Gradient Boosting were compared using an 80/20 random split of the development dataset.

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Random Forest | 130.77 | 568.85 | 0.8487 |
| Gradient Boosting | 108.25 | 530.91 | 0.8682 |

Gradient Boosting performed better and was selected for the final predictions.

The selected model uses:
- `n_estimators=100`
- `learning_rate=0.1`
- `max_depth=3`
- `random_state=42`

### Validation

The primary validation approach was an 80/20 random split of `train-test.csv`, using `random_state=42`.

A chronological 80/20 split was also tested as a robustness check:

- MAE: 118.12
- RMSE: 632.90
- R²: 0.8274

The random split was used as the primary validation approach.

After model selection, the Gradient Boosting model was retrained using all 48,000 rows in `train-test.csv` and used to predict all 12,000 rows in `validation.csv`.

## December Predictions

The December input contains the fixed scenario for each day of December 2025.

Since the December input contains fewer features than the main development data, a compatible feature subset was used:

- pickup
- delivery
- distance
- equipment
- weight
- month
- day

The resulting predictions are stored in `december_predictions.csv`.

The provided scoring script was used to validate both prediction files and generate the December prediction chart.
